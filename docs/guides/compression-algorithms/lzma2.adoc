== Purpose

LZMA2 is an enhanced version of LZMA designed for better multi-threading support and improved handling of incompressible data. It's the default compression algorithm for modern 7-Zip archives.

== Key Characteristics

[cols="1,3"]
|===
|Property |Value

|Compression Ratio
|Excellent (same as LZMA)

|Compression Speed
|Slow to medium (single-threaded)

|Decompression Speed
|Fast

|Memory Usage
|Medium to high

|Multi-Threading
|Excellent support

|Best For
|Multi-core systems, modern archives, mixed content
|===

== When to Use LZMA2

**Choose LZMA2 when**:

* Working with mixed content (text + binary + compressed)
* Creating modern 7z archives (it's the default)
* Need better streaming support
* Want future-proof archives

**Use LZMA instead when**:

* Single-threaded environment
* Maintaining compatibility with old 7-Zip versions (<9.20)
* Slightly better compression ratio is critical

== Basic Usage

=== Create LZMA2 Archive

[source,ruby]
----
# Create with LZMA2 (modern default)
# :lzma2 is the default algorithm for 7z
Omnizip::Archive.create('backup.7z', format: :seven_zip,
                        algorithm: :lzma2, level: 9) do |archive|
  archive.add_directory('project/')
end
----

=== With Parallel Processing

Omnizip's codecs are pure Ruby and single-threaded: there is no
+parallel:+ or +threads:+ option. To use multiple cores, run
several archive operations in separate processes instead (see the
link:../advanced-features/parallel-processing.html[Parallel
Processing guide]).

== Advanced Configuration

=== Dictionary Size

LZMA2's dictionary size follows the compression +level:+. It can
also be set explicitly:

[source,ruby]
----
# 64 MB dictionary for large homogeneous datasets
Omnizip::Archive.create('dataset.7z', format: :seven_zip,
                        algorithm: :lzma2,
                        dict_size: 64 * 1024 * 1024) do |archive|
  archive.add_directory('mixed_data/')  # Text + images + binaries
end
----

== Performance Characteristics

=== Parallel Speedup

Not applicable: Omnizip's codecs are pure Ruby and single-threaded.
Compression of independent archives can be parallelized at the
process level (see the link:../advanced-features/parallel-processing.html[Parallel Processing guide]).

=== Incompressible Data Handling

LZMA2 handles incompressible data more efficiently:

[source]
----
File Type       LZMA Time    LZMA2 Time   Improvement
─────────────────────────────────────────────────────
JPEG images     45s          32s          ~30% faster
Mixed archive   60s          40s          ~33% faster
Video files     38s          25s          ~34% faster
Pure text       30s          30s          Same
----

== Use Cases

=== Server Backups

[source,ruby]
----
Omnizip.compress_directory(
  '/var/www/',
  'www-backup.7z',
  algorithm: :lzma2,
  level: 9
)
----

=== Large Dataset Compression

Process large datasets efficiently:

[source,ruby]
----
# Compress large research dataset
Omnizip::Archive.create('dataset.7z', format: :seven_zip,
                        algorithm: :lzma2, level: 9,
                        solid: true) do |archive|  # Better compression
  # Add gigabytes of data
  archive.add_directory('research_data/')
end
----

=== Software Build Artifacts

Package build outputs (BCJ filter for executables):

[source,ruby]
----
# Package release after build
Omnizip.compress_directory(
  'build/release/',
  "app-#{version}.7z",
  algorithm: :lzma2,
  level: 7,
  filters: [:bcj_x86]
)
----

== Command-Line Usage

[source,bash]
----
# Create LZMA2 archive
$ omnizip archive create backup.7z files/ \
    --algorithm lzma2 \
    --level 9
----

== Technical Details

**LZMA2 Improvements over LZMA**:

. **Chunk-Based**: Data divided into independent chunks (which is what allows multi-threaded encoders; Omnizip's is single-threaded)
. **Dictionary Reset**: Can reset dictionary between chunks
. **Uncompressed Chunks**: Stores incompressible data without overhead
. **Better Streaming**: Designed for better streaming support
. **Error Recovery**: Better error isolation (chunk-level vs. stream-level)
