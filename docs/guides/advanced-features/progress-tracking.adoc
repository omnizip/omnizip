== Purpose

Long compression and extraction jobs benefit from progress feedback.
Omnizip ships a standalone tracker — +Omnizip::Progress+ — with
percentage, throughput, and ETA calculation. The convenience methods
do not emit progress themselves: wrap your own loop with a tracker.

== Basic Tracking

Create a tracker, update it as work completes, read live stats:

[source,ruby]
----
tracker = Omnizip::Progress.track(total_files: 100, total_bytes: 1_000_000)

tracker.update(files: 10, bytes: 100_000, current_file: "file.txt")

tracker.percentage       # => 10.0
tracker.elapsed_seconds
tracker.eta_seconds
tracker.eta_formatted    # => "2m 30s"
----

== Reporters

=== Callback Reporter

Yield progress to a block:

[source,ruby]
----
tracker = Omnizip::Progress.track(total_files: 100,
                                  total_bytes: 1_000_000) do |progress|
  puts "#{progress.percentage}% complete"
end
----

=== Console Reporter

Render a terminal progress bar:

[source,ruby]
----
tracker = Omnizip::Progress.track(
  total_files: 100,
  total_bytes: 1_000_000,
  reporter: :console
)
----

=== Log Reporter

Write updates to a log file (pass the reporter instance):

[source,ruby]
----
reporter = Omnizip::Progress::LogReporter.new(
  log_file: 'compress.log', verbose: true
)

tracker = Omnizip::Progress.track(
  total_files: 100,
  total_bytes: 1_000_000,
  reporter: reporter
)
----

== Wrapping a Compression Job

Track a directory compression file by file:

[source,ruby]
----
files = Dir.glob('data/**/*').select { |f| File.file?(f) }
tracker = Omnizip::Progress.track(
  total_files: files.size,
  total_bytes: files.sum { |f| File.size(f) },
  reporter: :console
)

Omnizip::Archive.create('backup.zip') do |archive|
  files.each do |file|
    archive.add_file(file, file.delete_prefix('data/'))
    tracker.update(files: 1, bytes: File.size(file), current_file: file)
  end
end
----

== Web Application Integration

Broadcast progress from a background job:

[source,ruby]
----
class ArchiveJob < ApplicationJob
  def perform(user_id, file_paths)
    tracker = Omnizip::Progress.track(total_files: file_paths.size)

    file_paths.each_with_index do |path, i|
      process_file(path)
      tracker.update(files: 1, current_file: path)

      ActionCable.server.broadcast("archive_#{user_id}", {
        status: 'processing',
        files_done: i + 1,
        total_files: file_paths.size,
        percentage: tracker.percentage
      })
    end
  end
end
----
