== Purpose

== Purpose

Streaming operations allow you to process archives without loading entire files into memory. This is essential for handling large archives, web applications, and memory-constrained environments.

Omnizip's streaming classes live under +Omnizip::Zip+ (streaming is a ZIP feature; the 7z and TAR writers accept buffered adds through the link:../creating-archives.html[Archive facade]).

== Creating Archives with Streaming

=== Stream to File

Create ZIP archives by streaming entries one at a time:

[source,ruby]
----
require 'omnizip/zip/output_stream'

Omnizip::Zip::OutputStream.open('backup.zip') do |stream|
  Dir.glob('logs/*.log').each do |file|
    stream.put_next_entry(File.basename(file))
    File.open(file, 'rb') do |f|
      stream.write(f.read)
    end
  end
end
----

Per-entry compression method and level are supported:

[source,ruby]
----
stream.put_next_entry('data.bin', compression: :zstandard, level: 3)
----

=== Stream to Memory

Create ZIP archives in memory with +Omnizip::Buffer+:

[source,ruby]
----
zip_data = Omnizip::Buffer.create(:zip) do |archive|
  archive.add('report.txt', generate_report)
  archive.add('data.json', export_data.to_json)
end

send_data zip_data.read, filename: 'export.zip'  # StringIO

# Or straight from a Hash
zip_data = Omnizip::Buffer.create_from_hash(
  'report.txt' => generate_report,
  'data.json' => export_data.to_json
)
----

== Reading Archives with Streaming

=== Extract While Reading

Process each file as it's read from the archive:

[source,ruby]
----
require 'omnizip/zip/input_stream'

Omnizip::Zip::InputStream.open('large-archive.zip') do |stream|
  while (entry = stream.get_next_entry)
    next if entry.directory?

    case entry.name
    when /\.csv$/
      import_csv_data(stream.read)
    when /\.json$/
      process_json(stream.read)
    end
  end
end
----

=== Extract to Memory

Read all entries into a Hash without touching the filesystem:

[source,ruby]
----
files = Omnizip::Buffer.extract_to_memory(File.binread('backup.zip'))

files.each do |filename, content|
  process_file(filename, content)
end
----

== Web Application Examples

=== Rails Upload Processing

[source,ruby]
----
class ArchiveController < ApplicationController
  def upload
    uploaded = params[:archive]

    files = Omnizip::Buffer.extract_to_memory(uploaded.read)

    files.each do |filename, content|
      process_file(filename, content)
    end

    render json: { processed: files.count }
  end
end
----

=== API Response Streaming

[source,ruby]
----
get '/export' do
  content_type 'application/zip'
  attachment 'export.zip'

  zip_data = Omnizip::Buffer.create(:zip) do |archive|
    User.find_each do |user|
      archive.add("#{user.id}.json", user.to_json)
    end
  end

  zip_data.read
end
----
